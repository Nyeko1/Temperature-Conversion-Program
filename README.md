# Temperature Conversion Program (HTML/CSS/JS)

A user-friendly web application designed to convert temperatures between Celsius and Fahrenheit. This project demonstrates basic HTML structure, CSS styling, and JavaScript logic for interactive client-side operations.

## ✨ Features

* **Celsius to Fahrenheit Conversion:** Easily convert temperatures from Celsius to Fahrenheit.
* **Fahrenheit to Celsius Conversion:** Convert temperatures from Fahrenheit to Celsius.
* **Simple User Interface:** Clean and intuitive interface with input field and radio button selection.
* **Real-time Output:** Displays the converted temperature directly on the page.

## 🚀 How to Use

To run this temperature converter locally in your web browser:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/your-repo-name.git](https://github.com/YOUR_USERNAME/your-repo-name.git)
    cd your-repo-name
    ```
    (Remember to replace `YOUR_USERNAME` and `your-repo-name` with your actual GitHub username and repository name.)

2.  **Open `index.html`:**
    Simply open the `index.html` file in your preferred web browser (e.g., Chrome, Firefox, Edge, Safari). You can usually do this by double-clicking the file in your file explorer.

3.  **Start Converting:**
    * Enter a temperature value into the input box.
    * Select the desired conversion direction using the radio buttons (e.g., "Celsius➡️ Farenheit" or "Farenheit➡️ Celsius").
    * Click the "Submit" button to see the converted temperature displayed below.

## 💻 Technologies Used

* **HTML5:** For the structure and content of the web page.
* **CSS3:** For styling the user interface (via `styles.css`).
* **JavaScript:** For handling the conversion logic and updating the display (via `index.js`).
